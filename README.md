# 比較生産費説シミュレーター

数字を動かして、比較優位・機会費用・分業のしくみを学ぶ、高校社会科（公共／政治・経済）向けの学習ツールです。
ブラウザだけで動きます。サーバー、アカウント、APIキーは不要です。

- **シミュレーション**：2×2〜4×4の表を設定して、生産の配分と合計生産量の変化を試す
- **演習問題**：絶対優位・比較優位・機会費用・生産配分・よくある誤解（P01〜P05）。ヒント・類題つき、A4プリント対応
- **自習モード**：入門／標準 × 約15分／約30分の一本道。教師の説明なしで進められる

> 現在は **第1段階（基幹版）** です。第2・第3段階の予定は「使い方」画面の最後にまとめています。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作ります（例：`trade-simulator`。公開範囲は Public）。
2. このフォルダの中身（`index.html`、`css/`、`js/`、`README.md` など）を、そのリポジトリにアップロードします。
   - ブラウザで行う場合：リポジトリの画面で「Add file」→「Upload files」→ ファイルをドラッグ →「Commit changes」。
   - `css` と `js` は**フォルダごと**入れてください。
3. リポジトリの「Settings」→ 左の「Pages」を開きます。
4. 「Build and deployment」の Source を「Deploy from a branch」にし、Branch を `main`、フォルダを `/ (root)` にして「Save」。
5. 1〜2分待つと、`https://（ユーザー名）.github.io/trade-simulator/` で開けるようになります。このURLを生徒に配ります。

## 手元で試す

`index.html` をダブルクリックしても動きます。
ただし「リンクをコピー」などの一部の機能はブラウザの制限で動かないことがあるので、次のように簡易サーバーで開くのが確実です。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

## 計算モデルと、判定する範囲

- 表の数値は「同じ労働量をすべてその商品に使ったときに作れる量」です（必要労働時間の表は第2段階で追加予定）。
- 生産性は一定、労働は自由に分けられる、規模に関して収穫一定、という簡略なモデルです。
- 機会費用 = （もう一方の財の生産量）÷（その財の生産量）。分数のまま厳密に比べます。機会費用が同じときは「比較優位に差はない」と判定します。
- 3か国以上・3財以上では、「どこが何を作るべきか」を自動で1つに決めません。何を最大化するかの条件が必要だからです。代わりに2国・2財を選んで比べる形にしています。
- 「完全分業なら両方の財が必ず増える」とは表示しません（初期例題では商品Bが4.5個から4個に減ります）。

## データとプライバシー

- 保存先はすべてブラウザ内（localStorage）です。外部への送信はありません。別の端末には引き継がれません。
- 共有端末では、トップ下の「学習記録を削除」で記録を消せます（保存した例題は残ります）。
- 国名・商品名などはHTMLとして解釈しません。
